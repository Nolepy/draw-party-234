# Draw Party 234 MiniGames

Game mabar 2–4 pemain dalam satu HP (offline). Mode: Sel Rebutan, Sumo Blob, Rebutan Makanan, atau Gabungan.

- `docs/index.html` : game (disajikan lewat GitHub Pages)
- `android/` : cangkang aplikasi Android (WebView) yang membuka game
- `.github/workflows/build-apk.yml` : membuat APK otomatis dan menaruhnya di Releases
